# Styling and localization

UX Driver serializes Driver.js text options from PHP and Twig.

## Text

```twig
<twig:Driver:Tour
    id="checkout-tour"
    progressText="{{ '{{current}}' }} / {{ '{{total}}' }}"
    nextBtnText="Next"
    prevBtnText="Back"
    doneBtnText="Done"
>
    ...
</twig:Driver:Tour>
```

For Hints, use `buttonText`:

```twig
<twig:Driver:Hints id="checkout-help" buttonText="Done">
    ...
</twig:Driver:Hints>
```

These text values are escaped by default because Driver.js writes them with `innerHTML`.

## Popover CSS

Use `popoverClass` to add a class to the Driver.js popover wrapper:

```twig
<twig:Driver:Tour id="checkout-tour" popoverClass="checkout-popover">
    ...
</twig:Driver:Tour>
```

```css
.driver-popover.checkout-popover {
  background-color: #111827;
  color: #f9fafb;
}

.driver-popover.checkout-popover .driver-popover-title {
  color: #ffffff;
}

.driver-popover.checkout-popover .driver-popover-description,
.driver-popover.checkout-popover .driver-popover-progress-text {
  color: #d1d5db;
}

.driver-popover.checkout-popover .driver-popover-footer-btn {
  background-color: #f9fafb;
  color: #111827;
}

.driver-popover.checkout-popover .driver-popover-arrow-side-left {
  border-left-color: #111827;
}

.driver-popover.checkout-popover .driver-popover-arrow-side-right {
  border-right-color: #111827;
}

.driver-popover.checkout-popover .driver-popover-arrow-side-top {
  border-top-color: #111827;
}

.driver-popover.checkout-popover .driver-popover-arrow-side-bottom {
  border-bottom-color: #111827;
}
```

Driver.js 1.8 exposes `--driver-popover-font-family` for the popover font. Other popover colors are styled through classes such as `.driver-popover`, `.driver-popover-title`, `.driver-popover-description`, `.driver-popover-footer`, `.driver-popover-progress-text`, `.driver-popover-footer-btn`, `.driver-popover-arrow`, `.driver-overlay`, and `.driver-active-element`.

Hints add `.driver-hint`, `.driver-hint-dot`, `.driver-hint-pulse`, `.driver-hint-popover`, and `.driver-hint-overlay`. Their CSS exposes `--driver-hint-size`, `--driver-hint-color`, and `--driver-hint-animation-duration`.

## Motion and accessibility

Set `:animate="false"` when you want a no-animation Tour. The bundle does not automatically read `prefers-reduced-motion`; keep that decision in your app when needed.

Keep titles short, button text explicit, and do not rely on color alone in custom themes.
